## 赛项背景与主题

本赛项紧扣十五五 **应急管理现代化** 要求，聚焦突发灾害、事故救援场景，突出智能技术在应急领域的**落地应用**。

智能+工程创新赛道以人工智能和大数据等技术的行业应用和未来发展为主题，将 AI 技术应用于智能搬运、智能分拣、**智能救援**等应用场景，培育"智能 + 制造 + 民生 + 应急"复合型人才。

本赛项要求参赛队自主设计并制作一台在指定模拟救援场景内按照要求完成救援任务的**智能救援机器人**。每场比赛同时上场两个队各一台救援机器人，要求救援机器人能够在保护自己免受对方干扰和碰撞的情况下，将尽可能多的救援目标转运至指定的安全区内。

## 救援机器人设计要求

> ⚠️ 如果不符合下列各项要求，取消比赛资格；若已经参赛，取消比赛成绩。

### 功能要求

在比赛过程中，救援机器人必须采用**完全自主运行**模式，应具备以下功能：

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | **自主运行** | 必须完全自主运行，不允许任何形式的遥控 |
| 2 | **高速移动** | 具备快速行驶能力，在场地内灵活移动 |
| 3 | **避障** | 避开场地上的障碍物及对方救援机器人 |
| 4 | **越障** | 跨越减速带等场地障碍 |
| 5 | **搜索与转运** | 在场地中搜索救援目标并将目标转运至本队安全区 |
| 6 | **对象识别** | 识别二维码、条码、文字、图像、形状、颜色、温度、振动等 |
| 7 | **碰撞保护** | 在两台机器人发生碰撞时保护自身不受损坏 |
| 8 | **失控保护** | 具备失控时的安全保护机制 |

### 电控及驱动要求

- 传感器和电机的种类及数量不限
- 比赛过程中**不能更换**任何电子元器件
- 允许与笔记本电脑进行通讯，但运行过程中**不能触碰**笔记本电脑
- 不允许用其他任何方式对救援机器人进行**遥控**
- 只能使用**一个**随机器人装载的内置电源（不能使用液体及对环境有腐蚀、污染的电源）
- 比赛过程中（含调试）**不能更换**电源

### 机械结构要求

- 自主设计并制造，除标准件外非标零件应自主设计和制造
- **不允许**使用购买的成品套件拼装而成
- 应**方便拆装和更换**
- 结构应具有一定强度，提升**抗干扰能力**
- 在受到碰撞、翻倒、跌落等情况后仍不影响正常工作
- 比赛过程中（含调试）**不能更换**任何零部件

### 外形尺寸、重量及颜色要求

| 参数 | 要求 |
|------|------|
| 重量 | **≤ 1.5 kg** |
| 尺寸（长×宽） | 出发时铅垂方向投影 ≤ **300mm × 300mm** |
| 高度 | ≤ **200mm**（包括所有软质线路） |
| 颜色/图案 | 禁止外表面装饰误导性图案及救援目标颜色 |

### 安全性要求

1. 禁用有伤害、破坏、易燃、易爆等危险机构或装置
2. 不允许使用 EMP 发生器等任何可以干扰对方的电子干扰设备
3. 不允许使用强光、激光等妨碍视线或视力的发射器
4. 除行驶轮以外的所有高速旋转结构件必须采用**非金属材质**
5. 禁止使用可能造成人身伤害的锋利结构

## 赛项具体要求

### 初赛

初赛由 **任务命题文档（30%）** 和 **现场初赛（70%）** 两个环节组成。根据初赛成绩及晋级比例确定晋级决赛的参赛队，初赛成绩不带入决赛。

#### 任务命题文档（第一环节）

按照国赛任务命题文档模版要求，参赛队提交决赛任务命题方案，必须策划以下内容：

- 决赛场景和场地规划（安全区、出发区）
- 三种救援目标的各自数量、形状、材质、颜色、重量、大小、位置和姿态
- 救援机器人转运救援目标的方式
- 保证在创新实践环节中必须进行救援机器人相关零部件的设计及制造

**评分说明：**

| 评分项 | 满分 |
|--------|------|
| 内容质量 | 75 分 |
| 排版规范 | 25 分 |

> ⚠️ 若文档雷同，或文档中出现校名、姓名、队名、特殊标记符号等，文档成绩为 **0 分**。

**成绩计算：**

```
A = 100 × 本队文档得分 / 参赛队文档最高得分
文档得分 = Σ(p_i) / n （p_i 为匿名网评专家打分，n 为评审专家总数）
```

#### 现场初赛（第二环节）

**1. 检录与抽签**

按上场顺序检录，现场抽签确定：
- 对阵方
- 场地号
- 红蓝方
- 出发位置（1-4 号出发区）

**2. 调试阶段（3 分钟）**

- 每队最多派 **2 名队员**进入场地调试
- 剩余 **30 秒**时：停止运行 → 将机器人放置在抽签确定的出发区 → 待机发车
- 助理裁判将各类目标摆放好

**3. 比赛启动**

- 裁判发出统一开始指令
- 参赛队**一键启动**救援机器人（机器人上须有明确标识）
- 必须在规定启动时间内离开出发区，否则本轮比赛结束

**4. 运行过程（3 分钟）—— 转运规则**

```
┌─────────────────────────────────────────────────────┐
│ 步骤 1（必须首先完成）：                               │
│   将 1 个普通物资单独转运至本队安全区物资区围栏内侧       │
│   （多于 1 个无效）                                   │
│                                                      │
│ 步骤 2（步骤 1 完成后才可进行）：                       │
│   · 一次转运不超过 3 个救援目标（超过无效）              │
│   · 可同时转运普通物资 + 核心物资                      │
│   · 伤员必须单独转运，一次只能转运 1 个                  │
│   · 禁止转运危险目标至安全区                           │
│   · 禁止抓取救援目标或将其放置在机器人上                 │
│   · 禁止进入对方安全区                                │
│   · 禁止将对方安全区内的目标以任何方式移出               │
└─────────────────────────────────────────────────────┘
```

**5. 对抗规则**

- 双方**不能主动**恶意进攻对方
- 两台机器人接触超过 **10 秒** → 强制分离，放回各自出发区继续运行（计时不中断）
- 不能将对方安全区内的救援目标以任何方式使其离开安全区（否则比赛结束）
- 不得损坏场地等赛场设施；裁判员有权为保护设施而终止比赛

**6. 比赛结束条件**

- 规定运行时间（3 分钟）到
- 救援目标被全部移至安全区内（不含围栏上）
- 机器人停止运行 15 秒
- 发生违规导致比赛终止

**7. 场次与成绩**

- 随机抽签产生每个参赛队 **2-3 场比赛**
- 按每场安全区内救援目标数量及评分规则计算成绩
- 取**所有场次成绩的平均值**作为现场初赛成绩

**8. 排名规则（同分时顺次比较）**

1. 现场初赛成绩得分高者优先
2. 所有轮次完成救援目标总数多者优先
3. 仍无法区分 → 抽签决定

### 决赛

决赛由 **创新实践（30%）** 和 **现场决赛（70%）** 两个环节组成。

#### 创新实践环节（第三环节）

**入场与命题发布：**

1. 按去掉未晋级队伍后的新顺序就坐、检录
2. 现场确定场地布置，以及目标的颜色、摆放位置和姿态等信息

**核心任务：**

在规定时间内完成以下任务：
- 按决赛命题将**自带零部件**更换在参赛作品上
- 完成该环节的**编程、装配、调试**
- 完成**答题**任务
- 完成**环境整理**

**综合评价：**

对参赛队的以下方面进行综合评价：
- 工程知识
- 诚信意识
- 安全意识
- 环境意识

**结束流程：**

调试结束 → 检验作品 → 交作品 → 离场

**自备物品清单：**

| ✅ 可携带 | ❌ 禁止携带 |
|-----------|-------------|
| 拆装工具 | 有安全隐患的物品 |
| 调试工具 | （违规者取消资格） |
| 相关设计软件 | |
| 手提电脑 | |
| 备用相关备件 | |

**成绩组成：**

```
C = C1 + C2
```
- **C1 = 60 分**：工程知识成绩
- **C2 = 40 分**：综合素质成绩

**综合素质扣分标准：**

| 违规行为 | 扣分 |
|----------|------|
| 不符合安全操作规程 / 不爱惜工作台 | 扣 20 分 |
| 造成安全事故或工作台损坏 | 扣 40 分 + 取消资格 |
| 超时 5 分钟以内 | 扣 20 分 |
| 超时 5 分钟以上 | 扣 40 分 + 不能参加后续环节 |
| 卫生、纪律等其他事宜 | 现场裁判酌情扣分 |

> 扣分可累加，扣完为止。

#### 现场决赛（第四环节）

- 抽签确定：场地号、红蓝方、对阵方及出发位置
- 参照现场初赛流程和转运规则完成救援目标转运任务
- 具体评分与规则**决赛现场公布**

**排名规则（同分时顺次比较）：**

1. 现场决赛成绩得分高者优先
2. 完成救援目标数多者优先
3. 仍无法区分 → 抽签决定

## 救援目标

### 通用特性

- 形式：抽象几何体及其组合（圆柱体、正方体、三棱锥、球体、锥体等）或物品微缩体
- 颜色：红色、黄色、蓝色、橘色、绿色、棕色、黑色、浅蓝、白色等
- 最大尺寸 ≤ **140mm**
- 最大重量 ≤ **800g**
- 材料：3D 打印 ABS / PLA
- 所有救援目标均为双方的**公共救援目标**（危险目标除外）
- 摆放位置及姿态可随机

| 伤员 | 4 个 | 橘色 PLA，80×40×40mm 长方体 | **15 分** |
| 危险目标 | 4 个 | 浅蓝，边长 40mm 正方体 | **禁止转运** |

## 评分规则汇总

### 计分办法

按正确移入本队安全区内（**全部进入安全区，不含安全区围栏上**）的救援目标数量计分：

| 目标类型 | 分值 |
|----------|:----:|
| 普通物资救援目标 | **5 分/个** |
| 核心物资救援目标 | **10 分/个** |
| 伤员救援目标 | **15 分/个** |

> 💡 对方将救援目标移至本队安全区内，计入本队数量。
>
> 💡 救援目标从安全区被弹出不扣分；已被撞出安全区的目标放回安全区，不扣原有分数。

### 扣分项

| 违规行为 | 扣分 |
|----------|:----:|
| 物资放入伤员区 / 伤员放入物资区（含部分进入） | **-10 分/个** |
| 进入对方安全区（含压在围栏上） | **-5 分/次** |
| 将救援目标移出比赛场地 | 按种类数量扣分 |

> 扣分可累加，直至成绩扣完。扣分后将救援目标随机放回场地中心/中部。

### 导致本轮比赛结束的违规行为

| 违规行为 | 后果 |
|----------|------|
| 将危险目标移到安全区（含围栏上） | 本轮结束 |
| 首次转运不是 1 个普通物资（多于 1 个无效） | 本轮结束，本次转运成绩无效 |
| 一次转运救援目标数量超过 3 个 | 本轮结束，本次转运成绩无效 |
| 转运伤员时目标总数超过 1 个 | 本轮结束，本次转运成绩无效 |
| 主动向对方发起进攻 | 本轮结束 |
| 将危险目标移出场地 | 本轮结束 |
| 将对方安全区内目标移出 | 本轮结束 |
| 机器人出现失控情况 | 本轮结束 |
| 安全事故（起火、破坏赛场/地面等） | 本轮结束 + 取消后续资格 |
| 机器人停止运行 15 秒 | 本轮结束 |

### 成绩计算公式

```
初赛 ─────────────────────────────
  文档得分：A = 100 × 本队文档得分 / 最高文档得分
  现场初赛：B = 100 × 本队平均得分 / 最高平均得分
  初赛总成绩：P = A × 30% + B × 70%

决赛 ─────────────────────────────
  创新实践：C = C1(工程知识60分) + C2(综合素质40分)
  现场决赛：D = 100 × 本队得分 / 最高得分
  决赛总成绩：F = C × 30% + D × 70%
```
